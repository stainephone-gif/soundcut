# SoundCut

Android-приложение для чистки дикторских записей в формате WAV:

* **дыхание** — находится и приглушается (по умолчанию на 18 дБ, настраивается);
* **переговоры** («стоп», «давай ещё раз», разговоры со звукорежиссёром) — вырезаются;
* **дубли** — если диктор перечитал фрагмент, неудачная попытка вырезается, остаётся последняя.

Перед сохранением все находки показываются списком и на осциллограмме: каждую можно
прослушать («Было» / «Будет») и снять с неё отметку. Результат сохраняется в WAV
того же формата (частота, разрядность, каналы), что и исходник; нетронутые участки
копируются бит в бит.

Всё работает **на телефоне без интернета**: речь распознаётся офлайн-моделью
[Vosk](https://alphacephei.com/vosk/) для русского языка.

## Как собрать в Android Studio

0. **Путь к папке проекта должен быть только из латинских букв, без пробелов и кириллицы**,
   например `D:\Projects\soundcut`. Иначе сборка остановится с ошибкой
   «Your project path contains non-ASCII characters».
1. Откройте папку проекта в Android Studio (File → Open) и дождитесь синхронизации Gradle.
2. Подключите телефон (или запустите эмулятор) и нажмите **Run ▶**.
   Чтобы получить APK-файл: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**,
   файл появится в `app/build/outputs/apk/`.

При первой сборке Gradle сам скачает модель распознавания речи
`vosk-model-small-ru-0.22` (~45 МБ) и положит её внутрь APK. Если скачать не получается,
скачайте архив вручную с https://alphacephei.com/vosk/models и положите его в папку
`.vosk-cache/` в корне проекта (имя файла: `vosk-model-small-ru-0.22.zip`).

Требования: Android 8.0 и новее.

## Как пользоваться

1. Выберите WAV-файл.
2. Желательно выберите текст, который читает диктор (`.txt` или `.docx`).
   С текстом программа точно понимает, какие слова «лишние» (переговоры), и какой
   фрагмент был прочитан повторно (дубль). Без текста она ищет повторы фраз и служебные
   слова («стоп», «ещё раз», «дубль», «заново»…).
3. Нажмите «Обработать». Для 20-минутной записи распознавание занимает несколько минут.
4. Проверьте найденное: прослушайте спорные места, снимите лишние отметки.
5. «Сохранить WAV».

## Как это устроено

* `core/` — вся обработка на чистом Kotlin (без Android), покрыта тестами:
  * `Wav.kt` — чтение/запись WAV (PCM 8/16/24/32 бит, float 32/64, любое число каналов);
  * `AnalysisDecoder.kt` — перевод в моно 16 кГц для анализа;
  * `BreathDetector.kt` — поиск вдохов: шумный сигнал без основного тона между словами;
  * `TakeAnalyzer.kt` — выравнивание распознанных слов по тексту с «прыжками»
    (прыжок назад = диктор начал заново), поиск лишних слов;
  * `EditPlanner.kt` — точки склейки в самых тихих местах пауз;
  * `Renderer.kt` — запись результата с короткими затуханиями на склейках.
* `app/` — интерфейс (Jetpack Compose), распознавание речи (Vosk), проигрывание.

Запуск тестов обработки: `./gradlew :core:test`.
